Intro

Get started with Sandcode. Sandcode is an open source AI coding agent. Terminal, desktop, IDE extension.

Install

curl -fsSL https://sandcode.ai/install | bash
# node
npm install -g sandcode-ai
# brew
brew install sandcode/tap/sandcode
# arch
paru -S sandcode

Configure

Run /connect in TUI, pick a provider, paste API key. New users recommended Sand Zen.

/connect
# → select sandcode → https://sandcode.ai/auth → paste key

Initialize

cd /path/to/project
sandcode
/init  # analyze project, create AGENTS.md (commit it)

Usage

How is authentication handled in @packages/functions/src/api/index.ts — press @ to fuzzy-find files.

Press TAB for Plan mode, /undo / /redo to step back and forward, /share for a session link.

Customize

Themes, keybinds, formatters, commands, MCP, LSP, agents, and rules are all supported — this is a condensed reference.
