FAQ

Is installing SandCode free?

Yes. The CLI and the setup wizard cost nothing. Usage needs a plan — Standard is $9.9/mo, and the PAYG wallet has no monthly fee at all.

Do I need a particular editor?

No. Any client that accepts a custom base URL can use your pool, and setup configures each one it finds on your machine.

Which endpoints does it use?

An OpenAI-compatible chat-completions endpoint and an Anthropic-compatible messages endpoint, both under https://api.sandcode.ai/v1.

What exactly does setup write to my machine?

Client config files (endpoint and MCP entries), a rules file compiled into each client's format, and short-lived revocable tokens. It prompts before the first write, and sandbase harness off disables the local harness.
