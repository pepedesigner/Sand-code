FAQ

What is Sandcode?

An open source AI coding agent that runs in your terminal, IDE, or desktop — reading, editing, and shipping code with you.

How do I use Sandcode?

Install with curl -fsSL https://sandcode.ai/install | bash, open your project, run sandcode, then /init to generate an AGENTS.md.

How much does Sandcode cost?

The core is free and open source. Zen and Go plans are usage-based, starting at $1–$20 with caps and instant cancel.

What about data and privacy?

Zero retention by default — your code is never used for training. Teams get SSO, audit logs, and private deployment.

Is Sandcode open source?

Yes. Star it, open issues, and send PRs — all welcome.
